# Security Policy

## Supported Versions

Security fixes are released for the current stable GitHub release. Prerelease
and older versions should be upgraded before a report is investigated.

## Reporting a Vulnerability

Send vulnerability reports privately to `claworld@xfx.studio`.

Include the affected release tag, reproduction steps, expected impact, and any
relevant logs with credentials and personal data removed. Do not open a public
issue for an undisclosed vulnerability.

XFX Studio will acknowledge a complete report within five business days and
coordinate remediation and disclosure with the reporter.
